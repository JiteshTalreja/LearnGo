# LearnGo

This repository is a personal learning space for understanding Go from the ground up.

The goal is to move beyond writing small programs and build a solid understanding of how Go actually works under the hood: syntax, memory model, concurrency, interfaces, garbage collection, the standard library, tooling, and the internals that make Go efficient and practical.

## What this repo is for

Use this repository to:
- practice Go syntax and fundamentals
- explore language internals and runtime behavior
- document learnings and experiments
- build small projects and examples as understanding grows
- track progress while becoming comfortable with idiomatic Go

## Learning focus

This repo is meant to support deep learning in areas such as:
- Go basics: variables, functions, structs, slices, maps, pointers
- control flow and error handling
- packages and module management
- interfaces and polymorphism
- goroutines and channels
- mutexes, synchronization, and concurrency patterns
- memory management and garbage collection basics
- testing, benchmarking, and profiling
- standard library usage and idiomatic patterns
- compiler/runtime concepts and performance thinking

## Suggested study path

1. Learn the basics of Go syntax and structure.
2. Practice writing small programs and solving problems.
3. Study how common language features work internally.
4. Explore concurrency deeply with goroutines and channels.
5. Read the standard library and learn how Go tools are used in practice.
6. Build small projects to connect theory with real usage.

## Repo structure

This repository is intentionally simple for now. Over time, it can grow into:
- notes and summaries
- small example programs
- mini projects
- experiments around Go internals
- reference snippets and cheat sheets

## Getting started

If you do not already have Go installed, install it from the official site:
- https://go.dev/dl/

Verify your installation:

```bash
go version
```

Create a new module when you are ready:

```bash
go mod init learngo
```

## Notes

This repo is meant to be a personal knowledge base as much as a code workspace. The best way to use it is to keep adding examples, experiments, and notes as your understanding improves.

The aim is not just to know Go syntax, but to become comfortable with how Go behaves, why it behaves that way, and how to use it effectively in real-world systems.
